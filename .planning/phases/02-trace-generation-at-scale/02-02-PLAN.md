  <action>
Create `src/experimental/gorn/scripts/generate_traces.py` with:

**Main function (`main()`):**
1. Load config via `load_config()` (merges base.yaml + generate.yaml + CLI overrides)
2. Build the full problem list:
   - Call `load_gsm_symbolic_contamination(n_per_type=cfg.data.gsm_problems_per_type, seed=cfg.seed)` for GSM-Symbolic (returns ~200 problems: 100 fresh + 100 original, each with Yes/No verification format)
   - Call `load_folio(n=cfg.data.folio_problems, seed=cfg.seed)` for FOLIO (~100 problems)
   - Call `load_strategyqa(n=cfg.data.strategyqa_problems, seed=cfg.seed)` for StrategyQA (~100 problems)
   - Combine all into a single list
3. Log total problem count and per-dataset counts
4. Resolve GPU IDs from cfg.gpus
5. Call `run_parallel_isolated(generation_worker, all_problems, gpu_ids, cfg)`
6. Log results: how many workers succeeded, how many failed, and which GPU IDs failed
7. Log final message pointing to output directory

**Worker function (`generation_worker(rank, gpu_id, problems, cfg)`):**
1. Set up logging via `setup_logging(f"gen_worker_{rank}")`
2. Set CUDA device via `torch.cuda.set_device(gpu_id)`
3. Load model via `load_model(gpu_id=gpu_id, model_name=cfg.model.name)`
4. For each problem in assigned chunk:
   - For each trace_index in range(cfg.data.traces_per_problem):
     a. Compute output path via `get_trace_json_path(cfg.paths.traces_dir, problem["dataset_name"], problem["problem_id"], trace_index)`
     b. Also compute failed path via `get_failed_trace_json_path(cfg.paths.traces_dir, problem["dataset_name"], problem["problem_id"], trace_index)`
     c. **Resume check**: if either path exists, skip (log as "skipped")
     d. Derive seed via `derive_trace_seed(problem["problem_id"], trace_index)`
     e. Call `set_seed(seed)`
     f. Try: call `generate_trace(model, tokenizer, problem["verification_prompt"], max_new_tokens=cfg.model.max_new_tokens)`
     g. Convert output_ids to list: `token_list = output_ids[0].tolist()`
     h. Parse think boundaries via `parse_think_boundaries(token_list)`
     i. Check quality: `has_think = len(blocks) > 0`, `hit_max_tokens = (token_list[-1] != tokenizer.eos_token_id)` (but guard for empty token_list)
     j. Build trace_data dict:
        ```python
        {
            "token_ids": token_list,
            "generated_text": tokenizer.decode(token_list, skip_special_tokens=False),
            "metadata": {
                "problem_id": problem["problem_id"],
                "dataset_name": problem["dataset_name"],
                "ground_truth": problem["ground_truth"],
                "is_fresh": problem.get("is_fresh"),
                "original_answer": problem.get("original_answer"),
                "verification_prompt": problem["verification_prompt"],
                "trace_index": trace_index,
                "seed": seed,
                "num_tokens": len(token_list),
                "num_think_blocks": len(blocks),
                "hit_max_tokens": hit_max_tokens,
                "model_name": cfg.model.name,
                "max_new_tokens": cfg.model.max_new_tokens,
                "temperature": cfg.generation.temperature,
                "top_p": cfg.generation.top_p,
                "top_k": cfg.generation.top_k,
                "timestamp": time.time(),
            },
        }
        ```
     k. Route to valid/ or failed/: if `has_think`, write to valid path; else write to failed path
     l. Use `write_trace_json(trace_data, dest_path)` for atomic write
     m. Except Exception: log error with problem_id, trace_index, exception type and message; increment failed counter; continue
5. After all problems: del model, del tokenizer, gc.collect(), torch.cuda.empty_cache()
6. Log summary: completed, failed, skipped counts

**Script entry point:**
```python
if __name__ == "__main__":
    main()
```

**Run command:** `uv run python src/experimental/gorn/scripts/generate_traces.py --config src/experimental/gorn/configs/generate.yaml --gpus 0,1,2,3`

**Important details:**
- Import time at top for timestamps
- Import gc at top for cleanup
- Use `model._model.generate()` for generation (via `generate_trace()` which already does this)
- The `generate_trace()` function returns shape [1, total_seq_len] -- the token_list should include both input prompt tokens and generated tokens
- Do NOT save activations in this script. This is generation only.
- Do NOT import nnsight-related capture functions. This script only uses generate_trace().
- Plain text logging, no emoji, no decorative formatting
