  <action>
    Create storage.py with the following functions.

    **`save_trace(activations: dict[str, torch.Tensor], path: str, metadata: dict = None) -> None`:**
    - Takes a dict of named tensors (as produced by capture_activations in model.py)
    - Expected keys: residual_layer_{i}, last_token_layer_{i}, logits, topk_values, topk_indices, entropy, token_ids
    - Ensures all activation tensors are BF16 and on CPU before saving
    - Token IDs and topk_indices should be int32
    - topk_values and entropy should be BF16
    - Uses `safetensors.torch.save_file(tensors, path)` to write
    - Creates parent directories if they do not exist (os.makedirs)
    - If metadata provided, saves it alongside (see save_metadata)

    **`load_trace(path: str) -> dict[str, torch.Tensor]`:**
    - Uses `safetensors.torch.load_file(path)` to load all tensors
    - Returns dict of name -> tensor (on CPU, preserving original dtypes)

    **`prepare_trace_tensors(activations: dict[str, torch.Tensor], logits: torch.Tensor, token_ids: torch.Tensor, top_k: int = 50) -> dict[str, torch.Tensor]`:**
    - Takes raw outputs from capture_activations and processes them for storage
    - From activations dict: copies residual_layer_* and last_token_layer_* tensors, converts to BF16 CPU
    - From logits tensor [1, seq_len, vocab_size]:
      - Computes top-k: `torch.topk(logits[0], k=top_k, dim=-1)` -> values and indices
      - Stores as "topk_values" (BF16) and "topk_indices" (int32)
      - Computes entropy per position: `-(probs * probs.log()).sum(dim=-1)` using float32 probs for numerical stability, then cast result to BF16
      - Stores as "entropy" (BF16), shape [seq_len]
    - From token_ids: stores as "token_ids" (int32), 1D
    - Returns the complete dict ready for save_trace

    **`save_metadata(metadata: dict, path: str) -> None`:**
    - Saves metadata as JSON alongside trace file
    - path should be the metadata JSON path (e.g., replace .safetensors with .json, or use a separate metadata.json in the directory)
    - Metadata includes: problem_id, dataset_name, ground_truth, num_tokens, num_think_blocks, generation_params, timestamp
    - Creates parent directories if needed

    **`load_metadata(path: str) -> dict`:**
    - Loads metadata JSON from path
    - Returns dict

    **`get_trace_path(base_dir: str, dataset_name: str, problem_id: str, trace_idx: int) -> str`:**
    - Returns standardized path: {base_dir}/traces/{dataset_name}/{problem_id}/trace_{trace_idx:02d}.safetensors
    - This is the canonical path format for Phase 2 trace generation

    **`get_metadata_path(trace_path: str) -> str`:**
    - Given a .safetensors trace path, returns the companion .json metadata path
    - Simply replaces .safetensors extension with .json

    Important constraints:
    - No emoji in code or output
    - No mock data -- but this module can be tested with synthetic tensors (random BF16 tensors of correct shapes)
    - Fail loudly if safetensors save/load fails (no silent fallback)
  </action>
