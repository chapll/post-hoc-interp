## Decisions Made

- Imported probe_trace and helpers from force_answer_experiment.py via `sys.path.insert(0, ...)` and `from scripts.force_answer_experiment import ...`. This keeps a single source of truth for the probing logic, though it depends on load_dotenv being called before import.
- Created cfg_shim (OmegaConf dict with `force_answer` key) to bridge the cross_seed config to probe_trace's expected interface. probe_trace accesses `cfg.force_answer.num_probes` etc., so passing the full cross_seed config would cause ConfigAttributeError.
- Used run_parallel_isolated (not run_parallel) because cross-seed probing is a long job (~20-30 min) where one OOM should not abort all workers.
- Re-implemented select_problems inline (same logic as generate_seed_traces.py) rather than importing to avoid circular dependencies.
