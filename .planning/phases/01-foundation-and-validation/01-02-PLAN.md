  <action>
    Create datasets.py with the following functions. Each returns a list of dicts with a uniform schema.

    **Uniform problem schema** (all datasets produce this):
    ```python
    {
        "problem_id": str,           # unique ID: "{dataset}_{index}"
        "question": str,             # original question text
        "ground_truth": str,         # "Yes" or "No" -- probe label, matches prompt framing
        "dataset_name": str,         # "gsm_symbolic", "folio", "strategyqa"
        "original_answer": str,      # original answer from dataset
        "verification_prompt": str,  # full prompt for model input
        "presented_answer": str,     # what was presented for verification (for GSM: number, for FOLIO: conclusion, for StrategyQA: yes/no)
    }
    ```

    **CRITICAL: Probe labels are "Yes"/"No" strings, not True/False booleans.**
    The probe is trained to detect whether the model's internal state represents "Yes" or "No" in response to the verification question. This matches the "(Yes or No)" framing in every prompt. All downstream code (probe training, transition detection, evaluation) uses these string labels.

    **1. `load_gsm_symbolic(n: int = 300, seed: int = 137) -> list[dict]`:**
    - Load `apple/GSM-Symbolic` config="main" split="test" via `datasets.load_dataset`
    - Parse correct answer from `answer` field: split by "####", take last part, strip whitespace, convert to number (int if no decimal, else float)
    - For each problem, create TWO items:
      - Yes item: "Is the answer {correct_answer}?" -- ground_truth="Yes"
      - No item: "Is the answer {distractor}?" -- ground_truth="No"
    - Distractor generation: small perturbation of correct answer. For integer answers: add/subtract 1-10% of value (min offset 1-2). For zero: use +/-1 or +/-2. Ensure distractor != correct.
    - Verification prompt format:
      ```
      {question}

      Is the answer {presented_answer} (Yes or No)? Please think step-by-step to verify whether the answer is correct.
      ```
    - Balance to n/2 Yes + n/2 No, shuffle with seeded RNG
    - problem_id format: "gsm_symbolic_{original_row_index}_{true|false}"

    **2. `load_folio(n: int = 300, seed: int = 137) -> list[dict]`:**
    - Load `tasksource/folio` -- combine train + validation splits
    - CRITICAL: Filter OUT items where label == "Uncertain" (NOT "Unknown" -- the actual string in the dataset is "Uncertain")
    - "True" label -> ground_truth="Yes" (conclusion IS valid)
    - "False" label -> ground_truth="No" (conclusion is NOT valid)
    - Balance to minority class count, cap at n/2 per class
    - Verification prompt format:
      ```
      Given the following premises:
      {premises}

      Is the following conclusion valid: "{conclusion}" (Yes or No)?
      Please think step-by-step to verify whether this conclusion follows from the premises.
      ```
    - problem_id format: "folio_{index}"
    - Log actual counts: total rows, after filtering Uncertain, after balancing. If total < n, log a warning with actual count.

    **3. `load_strategyqa(n: int = 300, seed: int = 137) -> list[dict]`:**
    - Load `ChilleD/StrategyQA` split="train" (1600 rows -- larger split)
    - answer field is bool: True = yes, False = no
    - ground_truth = "Yes" if answer is True, "No" if answer is False
    - Balance to minority class count, cap at n/2 per class
    - Verification prompt format:
      ```
      Answer the following question (Yes or No): {question}
      Please think step-by-step to verify your answer.
      ```
    - presented_answer field: "yes" for Yes items, "no" for No items
    - problem_id format: "strategyqa_{index}"

    **4. `load_dataset_by_name(name: str, n: int = 300, seed: int = 137) -> list[dict]`:**
    - Dispatcher: maps "gsm_symbolic" -> load_gsm_symbolic, "folio" -> load_folio, "strategyqa" -> load_strategyqa
    - Raises ValueError for unknown dataset names

    **Important constraints:**
    - No emoji in any code, comments, or print/log statements
    - No seed 42 anywhere (default seed is 137)
    - No mock data or placeholder returns -- all functions load real data from HuggingFace
    - All functions must handle the case where available data is less than requested n (use what is available, log warning)
    - Use Python's `random.Random(seed)` for reproducible shuffling (do NOT modify global random state)
