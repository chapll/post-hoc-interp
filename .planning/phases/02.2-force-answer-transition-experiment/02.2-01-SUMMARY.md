## Decisions Made

- Used DynamicCache with crop() for cache-efficient probing (process probes in descending order so only the tail is cropped)
- Dual answer matching: token-level first (scan for Rho first-token or Tau token), string-level second (case-insensitive "rho"/"tau" in decoded text), disagreements flagged in output
- Fallback to simple per-position generation if DynamicCache approach fails (logged as warning)
- correct_token_rank computed via double argsort on float32 softmax probabilities (0-indexed)
- Proportional allocation across datasets using round() with a fixed RNG seed for reproducibility
