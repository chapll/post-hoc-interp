- `scripts/generate_seed_traces.py` - Targeted trace generation: selects ~41 correct problems, generates 17 new seed traces per problem using prompts extracted from existing trace metadata

## Decisions Made

- Re-implemented Phase 2.2 selection logic inline in `select_problems()` rather than importing from `force_answer_experiment.py`. This avoids import gymnastics (sys.path manipulation, config shim creation) and keeps the script self-contained.
- Extract `verification_prompt` from existing `trace_00.json` metadata rather than re-building from dataset loaders. This guarantees byte-identical prompts across all seeds for the same problem, avoiding Pitfall 3 from RESEARCH.md.
- Trace indices 3-19 generated; 0-2 left untouched. File-based resume skips existing files.
