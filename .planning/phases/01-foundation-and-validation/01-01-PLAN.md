  <action>
    **utils.py** -- Create utility module with:

    1. `set_seed(seed: int)` -- Sets random, numpy, torch seeds. Must raise ValueError if seed == 42. Sets torch.manual_seed, torch.cuda.manual_seed_all, random.seed, numpy random seed, and torch.backends.cudnn.deterministic = True.

    2. `get_device(gpu_id: int) -> torch.device` -- Returns torch.device(f"cuda:{gpu_id}") if CUDA available, otherwise raises RuntimeError (no silent CPU fallback).

    3. `setup_logging(name: str, level: str = "INFO") -> logging.Logger` -- Returns a Python logging.Logger with plain text format: "[{level}] {name}: {message}". No emoji, no decorative formatting. StreamHandler to stdout.

    **config.py** -- Create config loader with:

    1. `load_config(script_config: str = None) -> OmegaConf`:
       - Uses argparse with flags: --config (path to script-specific YAML, optional), --gpus (comma-separated GPU IDs, optional)
       - Loads base.yaml from src/experimental/gorn/configs/base.yaml (resolve path relative to this file using __file__)
       - If --config provided, loads that YAML and merges on top of base
       - Parses remaining unknown CLI args as OmegaConf dotlist overrides (e.g., model.name=foo)
       - If --gpus provided, overrides cfg.gpus with parsed list of ints
       - Returns merged OmegaConf DictConfig
       - Also accept a `script_config` kwarg for programmatic use (skips argparse when provided)

    **base.yaml** -- Default config at src/experimental/gorn/configs/base.yaml:
    ```yaml
    model:
      name: "Qwen/Qwen3-8B"
      dtype: "bfloat16"
      max_new_tokens: 8192

    generation:
      temperature: 0.6
      top_p: 0.95
      top_k: 20
      do_sample: true

    data:
      datasets:
        - gsm_symbolic
        - folio
        - strategyqa
      problems_per_dataset: 300
      traces_per_problem: 5

    storage:
      format: "safetensors"
      layer_subset: [0, 4, 8, 12, 16, 20, 24, 28, 32, 35]
      top_k_logits: 50
      save_attention: false

    gpus: [0]
    seed: 137

    paths:
      data_dir: "src/experimental/gorn/data"
      experiments_dir: "src/experimental/gorn/experiments"
    ```

    Important: Do NOT use seed 42. Default seed is 137.
    Important: All logging must be plain text. No emoji anywhere.
    Important: No fallback to CPU. get_device must error if CUDA unavailable.
  </action>
