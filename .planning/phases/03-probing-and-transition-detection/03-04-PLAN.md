Create `scripts/detect_transitions.py` that applies trained probes to generate per-token confidence curves and runs transition detection.

**Script structure:**

1. **Config and setup:**
   - `load_config("configs/phase3.yaml")`.
   - Load probe weights from safetensors files.
   - Load probe_aurocs.json to get best_layer and top_layers.
   - Load model on GPU.

2. **Probe loading (`load_probes`):**
   - Load safetensors file for each dataset + pooled.
   - Reconstruct nn.Linear(4096, 2) for each layer from `layer_{i}_weight` and `layer_{i}_bias`.
   - Move probes to GPU for fast inference.
   - Return dict: `probes[dataset][layer_idx] = nn.Linear`.

3. **Trace processing (`process_trace`):**
   - For each trace:
     a. Load trace JSON to get token_ids.
     b. Filter: single-think-block, has `</think>`.
     c. Get think content mask. Identify eligible probe positions: all True positions in mask, SKIPPING the first position after `<think>` (k=0, the `<think>` token content position is k=1 -- actually, the mask already excludes `<think>` and `</think>` boundary tokens, so position k=0 in the mask is already the first natural language token k=1). Verify: `get_think_content_mask` excludes boundary tokens per its docstring ("positions of boundary tokens themselves are excluded"). So the first True position IS the first natural language token. Start probing from the SECOND True position (skip k=0 which corresponds to the first content token right after `<think>` -- per CONTEXT.md: "SKIP probing the `<think>` token itself (geometric outlier, k=0). Start at first natural language token (k=1)."
     - Wait, re-reading: the `<think>` TOKEN is at position start. The mask marks start+1 to end-1. So mask[start+1] = True is the first content token AFTER `<think>`. Per REQ-P1, skip probing the `<think>` token itself. The mask already does this. But it says "Start at first natural language token (k=1)" where k=0 is `<think>`. So first True position in mask IS k=1. We probe all True positions in the mask.
     - Conclusion: probe ALL positions where mask is True. The mask already handles the skip.
     d. Run nnsight forward pass extracting residual stream at top-N layers.
     e. At each eligible position, apply the probe: `probe(residual[pos])` -> softmax -> confidence for class 1 (Yes).
     f. Produce confidence curve: arrays of (position, confidence) per layer.

4. **Transition detection (`detect_trace_transitions`):**
   - For each trace's confidence curve (at each layer):
     - Call `detect_transitions(positions, values, methods=cfg.phase3.transition.methods, config=transition_config)`.
     - Also call `sweep_pelt_penalties(positions, values, penalties=cfg.phase3.transition.pelt.penalties)` for PELT penalty sweep.
     - Store all results keyed by method.
   - Primary detection layer: best_layer from pilot.
   - Also run on other top-N layers for comparison (but primary is best_layer).

5. **Three-way classification:**
   - Per trace, using the best_layer results, classify as:
     - "clear": at least one method finds a transition AND plateau is detected
     - "no-signal": probe confidence stays below 0.70 throughout
     - "noisy-signal": everything else
   - Record the classification in the trace results.

6. **Output per trace:**
   - Save to `$DATA_DIR/results/phase3/transitions/{dataset}/{problem_id}_trace_{idx}.json`:
     ```json
     {
       "trace_id": "gsm_symbolic/problem_123/trace_00",
       "problem_id": "problem_123",
       "dataset": "gsm_symbolic",
       "classification": "clear",
       "best_layer": 20,
       "confidence_curve": {
         "positions": [5, 6, 7, ...],
         "values_layer_20": [0.12, 0.15, ...],
         "values_layer_18": [0.11, 0.14, ...],
         ...
       },
       "detection_results": {
         "layer_20": {
           "derivative": {"transition_point": 145, "classification": "clear", ...},
           "pelt": {"penalties": {1: {...}, 5: {...}, ...}},
           "binseg": {"transition_point": 142, ...},
           "sigmoid": {"transition_point": 148, "r_squared": 0.92, "sharpness": 0.08, ...}
         }
       }
     }
     ```

7. **Batch processing:**
   - Process all valid traces across all datasets.
   - Use tqdm progress bar.
   - For efficiency, batch traces that share similar sequence lengths for nnsight forward passes (optional optimization).
   - Report: total traces processed, classification distribution (clear/no-signal/noisy-signal) per dataset.

8. **Summary statistics:**
   - After processing all traces, print and save:
     - Classification distribution per dataset
     - Median transition point (normalized position) for clear traces per dataset per method
     - Indeterminate rate (no-signal + noisy-signal) prominently reported

- All detection methods run on RAW probe confidence values (no smoothing except for derivative).
- Detection runs per-trace, NOT averaged across traces (per locked decision).

  <files>scripts/compute_cosine_sim.py</files>
  <action>
Create `scripts/compute_cosine_sim.py` that computes step-wise cosine similarity S_t = cos(h_t, h_{t-1}) and runs pre-T vs post-T statistical comparison.

**Script structure:**

1. **Config and setup:**
   - Load config, probe_aurocs.json (for best_layer and top_layers), and transition results.
   - Load model on GPU.

2. **Layer selection for cosine similarity:**
   - Per REQ-P4: compute at "best-probe-AUROC layer plus 2-3 additional layers."
   - From probe_aurocs.json: get best_layer and 2-3 others from top_layers (e.g., if best is 20, also use 16, 24, 4).
   - Total: 3-4 layers for cosine similarity.

3. **Cosine similarity computation (`compute_trace_cosine`):**
   - For each trace:
     a. Load trace JSON for token_ids.
     b. Filter: single-think-block, has `</think>`.
     c. Get think content mask (eligible positions inside think block).
     d. Run nnsight forward pass extracting residual stream at the selected layers.
     e. At each pair of consecutive eligible positions (t, t-1):
        ```python
        S_t = F.cosine_similarity(h_t.unsqueeze(0), h_prev.unsqueeze(0), dim=-1).item()
        ```
     f. Produce S_t array per layer.

4. **Pre-T vs post-T comparison (`compare_pre_post`):**
   - Load transition detection results for each trace (from Plan 04 Task 1 output).
   - For traces classified as "clear" (has valid transition point):
     - Find T_i from detection results (use best method or primary method).
     - Split S_t array into pre-T (positions before T_i) and post-T (positions at/after T_i).
     - Compute Mann-Whitney U test: `scipy.stats.mannwhitneyu(pre, post, alternative='two-sided')`.
     - Compute Cohen's d: `(mean(post) - mean(pre)) / pooled_std`.
     - Record: pre_mean, post_mean, U statistic, p-value, Cohen's d, n_pre, n_post.
   - For traces without clean transitions, skip statistical comparison but still save S_t values.

5. **Output:**
   - Per-trace cosine similarity stored in the transition JSON files (append to existing):
     ```json
     "cosine_similarity": {
       "layer_20": {
         "positions": [6, 7, 8, ...],
         "S_t": [0.98, 0.97, 0.92, ...],
         "pre_post_comparison": {
           "pre_mean": 0.94,
           "post_mean": 0.99,
           "mann_whitney_u": 1234.0,
           "p_value": 0.0001,
           "cohens_d": 1.2,
           "n_pre": 120,
           "n_post": 80
         }
       },
       "layer_16": {...},
       ...
     }
     ```
   - Aggregate statistics saved to `$DATA_DIR/results/phase3/cosine_similarity_stats.json`:
     ```json
     {
       "per_dataset": {
         "gsm_symbolic": {
           "layer_20": {
             "n_clear_traces": 85,
             "mean_cohens_d": 1.1,
             "median_cohens_d": 1.05,
             "mean_p_value": 0.003,
             "fraction_significant_p05": 0.82,
             "mean_pre_mean": 0.93,
             "mean_post_mean": 0.98
           }
         }
       }
     }
     ```
   - Summary printed to stdout.

**Key constraints:**
- Cosine similarity computed per-trace, per-layer (never averaged across traces).
- Aggregation is over distributions of statistics, not over raw S_t curves.
- Only run pre/post comparison on "clear" transition traces.
- Fresh nnsight forward passes.
- No seed 42, no emoji.

**Usage:**
