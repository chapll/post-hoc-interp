  <name>Task 1: Build tokens.py for think boundary parsing</name>
  <files>src/experimental/gorn/lib/tokens.py</files>
  <action>
    Create tokens.py with:

    **Constants:**
    ```python
    THINK_TOKEN_ID = 151667    # <think>
    THINK_END_TOKEN_ID = 151668  # </think>
    ```

    **`parse_think_boundaries(token_ids: list[int]) -> list[tuple[int, int]]`:**
    - Finds all (start_idx, end_idx) pairs where start_idx is position of `<think>` (151667) and end_idx is position of matching `</think>` (151668)
    - Handles edge cases:
      - No think tokens: return empty list
      - Unclosed `<think>` (no matching `</think>`): include block with end_idx = len(token_ids) - 1, log warning
      - Multiple blocks: return all blocks in order
      - Nested think tokens: treat as sequential (inner `<think>` starts new block if prior was closed)
    - Returns list of (start, end) tuples

    **`get_think_content_mask(token_ids: list[int]) -> list[bool]`:**
    - Returns a boolean mask of length len(token_ids)
    - True for positions INSIDE think blocks (excluding the `<think>` token itself at start, but including `</think>` at end is optional -- prefer excluding both boundary tokens)
    - Specifically: for block (start, end), mask is True for positions start+1 to end-1 (content only, not the boundary tokens themselves)
    - This is used for probing: we probe inside think blocks but skip `<think>` token (geometric outlier per Cox protocol)

    **`count_think_blocks(token_ids: list[int]) -> int`:**
    - Returns number of think blocks found
    - Used for filtering: primarily keep single-block traces

    **`get_pre_handoff_window(token_ids: list[int], window_size: int = 3) -> tuple[int, int] | None`:**
    - Finds the FINAL `</think>` token position
    - Returns (start_pos, end_pos) for the window of `window_size` tokens immediately before that final `</think>`
    - Returns None if no `</think>` found
    - start_pos is inclusive, end_pos is exclusive (standard Python slice convention)
    - This is the "Pre-Handoff Window" for Train-on-End probe training

    Important: These operate on token ID lists (integers), NOT on strings. Token ID based parsing is required because `<think>` and `</think>` have special=false and string parsing is fragile.
  </action>
  <verify>

<task type="auto">
  <name>Task 2: Build model.py with nnsight integration and smoke test on GPU</name>
  <files>src/experimental/gorn/lib/model.py</files>
  <action>
    Create model.py with the following functions. This is the critical nnsight + Qwen3 validation.

    **`load_model(gpu_id: int = 0) -> tuple[LanguageModel, PreTrainedTokenizerBase]`:**
    - Loads Qwen3-8B via nnsight: `LanguageModel("Qwen/Qwen3-8B", device_map=f"cuda:{gpu_id}", torch_dtype=torch.bfloat16, dispatch=True)`
    - Gets tokenizer from model (nnsight exposes it as model.tokenizer)
    - Returns (model, tokenizer) tuple
    - Logs model load time and GPU memory usage

    **`generate_trace(model, tokenizer, prompt_text: str, max_new_tokens: int = 8192) -> torch.Tensor`:**
    - Formats prompt using tokenizer.apply_chat_template with enable_thinking=True
    - Tokenizes and moves to model device
    - Generates with Qwen3 thinking-mode params: temperature=0.6, top_p=0.95, top_k=20, do_sample=True
    - CRITICAL: Use model._model.generate() to access the raw HuggingFace model for generation (nnsight's .generate() may have issues per research doc). If model._model doesn't work, try model.model or the underlying model attribute.
    - Returns full output token IDs tensor (including input tokens)
    - Wraps in torch.no_grad()

    **`capture_activations(model, token_ids: torch.Tensor, layer_subset: list[int] = None, num_layers: int = 36) -> dict[str, torch.Tensor]`:**
    - Default layer_subset: [0, 4, 8, 12, 16, 20, 24, 28, 32, 35]
    - Uses nnsight `.trace()` context manager on the full token sequence
    - Captures:
      1. Full-sequence residual stream at each layer in layer_subset: key = f"residual_layer_{idx}", shape [1, seq_len, 4096]
      2. Last-token activations at ALL 36 layers: key = f"last_token_layer_{idx}", shape [1, 4096]
      3. Full logits from lm_head: key = "logits", shape [1, seq_len, vocab_size]
    - CRITICAL: Use .save() on every proxy value to persist after trace context exits
    - CRITICAL: Use model.model.layers[idx].output[0] (NOT .output without [0] -- it's a tuple)
    - After trace context: convert all saved proxies to actual tensors, move to CPU, ensure BF16 dtype for activations
    - Returns dict of string -> tensor

    **Important implementation notes:**
    - If nnsight fails to load Qwen3-8B or trace fails with errors, the code must error loudly. No fallback to CPU, no mock data, no silent degradation.
    - If nnsight's LanguageModel wrapping causes issues with generate, use the underlying model directly: `model._model.generate()` per the research doc recommendation.
    - Log activation shapes after capture for validation.
    - This task REQUIRES GPU access. The smoke test should run on a machine with at least one GPU.
    - If running on a machine without GPU, the task cannot be completed -- skip the smoke test and document that GPU validation is pending.

    **Smoke test script** (inline, not a separate file):
    Run a minimal end-to-end test: load model, generate a short trace, capture activations, verify shapes. Use a simple prompt like "Is 2+2 equal to 4? Please think step-by-step to verify." with max_new_tokens=512 to keep it fast.
  </action>
