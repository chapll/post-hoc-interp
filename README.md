# cs224n-final-proj
final project repository for stanford cs224n

## getting started
install [uv](https://docs.astral.sh/uv/getting-started/installation/)
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```
you can now run any file simply by prepending `uv run` to the command:
```py
uv run torchrun /path/to/file.py ...
uv run python /path/to/file.py ...
```
