    **Config path resolution fix in src/infra/config.py:**

    The current `config.py` line 15 has:
    ```python
    _CONFIGS_DIR = Path(__file__).resolve().parent.parent / "configs"
    ```
    This was correct when the file was at `src/experimental/gorn/lib/config.py` (parent.parent = gorn/ which had configs/). Now at `src/infra/config.py`, parent.parent = `src/` which does NOT have configs/.

    Replace this with the project-root discovery pattern:
    ```python
    def _find_project_root() -> Path:
        """Walk up from this file to find the directory containing pyproject.toml."""
        current = Path(__file__).resolve().parent
        while current != current.parent:
            if (current / "pyproject.toml").exists():
                return current
            current = current.parent
        raise FileNotFoundError("Could not find project root (no pyproject.toml found)")

    _CONFIGS_DIR = _find_project_root() / "configs"
    ```

    Place the `_find_project_root()` function just before the `_CONFIGS_DIR` assignment.
