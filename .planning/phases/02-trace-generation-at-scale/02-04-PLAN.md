Create `src/experimental/gorn/scripts/capture_activations.py` with:

**`capture_all_layers_chunked(model, token_ids, chunk_size=12, num_layers=36, top_k=50)` function:**
1. Accept token_ids as a 1D tensor (or 2D with batch=1). Ensure batch dim exists for nnsight trace.
2. Iterate over layer chunks: chunk_idx from 0 to ceil(num_layers/chunk_size)-1
3. For each chunk:
   a. Determine start_layer and end_layer for this chunk
   b. Create a set `chunk_set = set(range(start_layer, end_layer))`
   c. Open `model.trace(input_ids)` context:
      - Iterate ALL layers 0..num_layers-1 in sequential order (MANDATORY for nnsight 0.5 to avoid OutOfOrderError)
      - For layers in chunk_set: `saved[idx] = model.model.layers[idx].output.save()`
      - For layers NOT in chunk_set: `_ = model.model.layers[idx].output` (access but don't save -- satisfies ordering without memory cost)
      - On the LAST chunk only: also save logits: `saved_logits = model.lm_head.output.save()`
   d. After trace context exits: move chunk results to CPU as BF16:
      ```python
      for idx in range(start_layer, end_layer):
          tensor = saved[idx].detach().cpu()
          # Squeeze batch dim: [1, seq_len, hidden] -> [seq_len, hidden]
          if tensor.dim() == 3 and tensor.shape[0] == 1:
              tensor = tensor.squeeze(0)
          all_results[f"residual_layer_{idx}"] = tensor.to(torch.bfloat16)
      ```
   e. Del saved, torch.cuda.empty_cache()
4. After all chunks: process logits from the last chunk:
   a. Get full logits tensor from saved_logits
   b. Squeeze batch dim
   c. Compute top-k values and indices (k=top_k)
   d. Compute entropy (float32 softmax for numerical stability, then cast result to BF16)
   e. Store: `topk_values` (BF16), `topk_indices` (int32), `entropy` (BF16)
5. Also store the token_ids as int32 in the results dict
6. Return the full results dict

**CRITICAL nnsight detail:** If the bare `_ = model.model.layers[idx].output` access does NOT work (causes error), fall back to saving a minimal slice: `model.model.layers[idx].output[:, 0:1, 0:1].save()` and discard it after the trace. Add a comment noting this fallback.

**`verify_logits(model, token_ids, captured_logits, rtol=0.01, atol=0.01)` function:**
1. Run a single forward pass on the full token sequence via `model.trace(input_ids)`
2. Save lm_head output
3. Compare last-token logits (argmax must match, and torch.allclose with given tolerances)
4. Return True/False and log the comparison details

**Worker function (`capture_worker(rank, gpu_id, trace_items, cfg)`):**
1. Set up logging, set CUDA device
2. Load model via `load_model(gpu_id=gpu_id)`
3. For each trace_item (a dict with dataset_name, problem_id, trace_index, token_ids):
   a. Compute activation output path via `get_activation_path(cfg.paths.activations_dir, ...)`
   b. Resume check: if path exists, skip
   c. Convert token_ids to tensor on the correct device
   d. Call `capture_all_layers_chunked(model, token_ids_tensor, chunk_size=cfg.capture.chunk_size, ...)`
   e. If cfg.capture.verify_logits: run `verify_logits()` on the first few traces (e.g., first 3 per worker) and log results. Skip verification on remaining traces for speed.
   f. Save via `save_trace(results, activation_path)` -- use the existing save_trace function from storage.py for safetensors
   g. Also save companion metadata JSON (use `save_metadata()` from storage.py) with: problem_id, dataset_name, trace_index, num_tokens, num_layers=36, chunk_size, logits_verified (bool), capture_timestamp
   h. Except Exception: log error, continue
4. Cleanup: del model, gc.collect, torch.cuda.empty_cache

**Main function (`main()`):**
1. Load config via `load_config()` (merges base.yaml + capture.yaml + CLI)
2. Scan `{cfg.paths.traces_dir}/valid/` for all `trace_*.json` files
3. Load each JSON, extract: dataset_name (from path or metadata), problem_id, trace_index, token_ids
4. Build a list of trace_items (lightweight dicts with just what the worker needs)
5. Filter out traces that already have activation files on disk (pre-scan for resume)
6. Log: total traces found, already captured, remaining to capture
7. If no remaining traces, exit with message
8. Call `run_parallel_isolated(capture_worker, remaining_items, gpu_ids, cfg)`
9. Log completion summary

**Run command:** `uv run python src/experimental/gorn/scripts/capture_activations.py --config src/experimental/gorn/configs/capture.yaml --gpus 0,1,2,3`

**Important details:**
- Token IDs come from the trace JSON's `token_ids` field (list of ints). Convert to torch.LongTensor on the worker GPU.
- Activations are stored WITHOUT batch dimension: [seq_len, hidden_dim] not [1, seq_len, hidden_dim]
- All 36 layers are captured (not the Phase 1 subset of 10)
- Logits verification compares argmax first (must match), then torch.allclose as secondary
- Disk space: log the size of each saved safetensors file and cumulative disk usage
- On the first trace per worker, log the exact shapes of all stored tensors for debugging
