<objective>
Train linear probes on residual stream activations at the top-N layers identified by the pilot. Extract activations for ALL valid traces (not just pilot subset), train per-dataset and pooled probes with full 5-fold stratified CV, run selectivity controls, and save probe weights as safetensors.

Purpose: Produce the trained probes needed for per-token confidence curve generation in Plan 04. The probes learn what "definitively knowing the answer" looks like from the Pre-Handoff Window, and will be applied to every intermediate token position to detect the transition.

Output: Probe weights (safetensors) per dataset and pooled, AUROC results JSON, AUROC comparison plot
</objective>

  <action>
Create `scripts/train_probes.py` that trains probes at the top-N layers for all traces, with CV, selectivity, and weight saving.

**Script structure:**

1. **Config and setup:**
   - `load_config("configs/phase3.yaml")`.
   - Load pilot results from `$DATA_DIR/results/phase3/pilot_layer_aurocs.json` to get `top_layers`.
   - `setup_logging()`, `set_seed(cfg.seed)`.

2. **Trace discovery (`discover_all_traces`):**
   - Walk ALL trace directories in `$DATA_DIR/traces/valid/{dataset}/{problem_id}/`.
   - For each problem, load trace_00.json (primary trace per problem).
   - Filter: single-think-block, has `</think>` token, has valid Pre-Handoff Window.
   - **Training uses correct traces ONLY** -- the probe learns from traces where the model got the answer right.
   - Record: trace_path, token_ids (as list of ints), ground_truth, dataset, problem_id.
   - Report counts per dataset and overall.

3. **Activation extraction at top-N layers (`extract_training_activations`):**
   - Load model on GPU.
   - For each trace, run nnsight forward pass extracting ONLY the top-N layers (from pilot).
   - Since we only need top-N layers (e.g., 6), a single nnsight pass suffices -- no chunking needed.
   - **IMPORTANT**: Access ALL layers sequentially (for idx in range(36)) but only `.save()` the ones in top_layers. This avoids nnsight OutOfOrderError.
   - Extract Pre-Handoff Window positions (3 tokens) at each top-N layer.
   - Cast to float32 immediately.
   - Accumulate: `training_data[layer][dataset]` = list of (X_vectors, y_labels).
   - Also accumulate `training_data[layer]["pooled"]` = combined across all datasets.
   - **Multi-GPU support**: Use `run_parallel` or `run_parallel_isolated` from `src/multiprocess.py` if cfg.gpus has multiple GPUs. Each worker loads model and processes a subset of traces. Workers return extracted vectors.
   - For single GPU, run in-process.

4. **Probe training with CV (`train_probes_cv`):**
   - For each scope in [per-dataset (3), pooled (1)]:
     - For each of the top-N layers:
       - Concatenate X vectors -> [n_samples, 4096], y labels -> [n_samples].
       - Run 5-fold stratified CV (StratifiedKFold, shuffle=True, random_state=137).
       - Per fold:
         - Initialize `nn.Linear(4096, 2)` (reset parameters each fold).
         - Train with Adam (lr=1e-3, weight_decay=1e-4), CrossEntropyLoss.
         - Early stopping: track validation loss, patience=10, max 100 epochs.
         - At best validation loss, record state dict.
         - Compute AUROC on validation fold using `roc_auc_score(y_val, softmax_probs[:, 1])`.
       - Record per-fold AUROC and mean AUROC.
   - Total probes: (3 datasets + 1 pooled) x N layers = ~24 probes with CV.

5. **Selectivity controls (`train_selectivity_controls`):**
   - For each scope x layer combination:
     - Run 10 random-label permutations.
     - Each permutation: shuffle y with a different RNG seed (base_seed + perm_idx), train with same 5-fold CV procedure.
     - Record mean CV AUROC per permutation.
     - Report mean and std of 10 random AUROCs.
     - Warn if mean random AUROC > 0.60.
   - This validates that real probes are finding genuine signal, not artifacts.

6. **Final probe training (`train_final_probes`):**
   - After CV (which is for evaluation only), retrain probes on ALL data (no train/val split) for each scope x layer.
   - These are the final weights used for downstream inference (confidence curves, steering).
   - **Save ALL 36 layers per dataset** (per locked decision): for the top-N layers, use the trained weights. For the remaining 30 layers, train quick probes (same procedure, just no CV needed -- single training run on full data). This ensures all 36 layers are available for Phase 5 steering.
   - Save probe weights as safetensors:
     - `$DATA_DIR/results/phase3/probes/{dataset}_probes.safetensors` -- keys: `layer_{i}_weight`, `layer_{i}_bias` for i in 0..35
     - `$DATA_DIR/results/phase3/probes/pooled_probes.safetensors` -- same format

7. **Results output:**
   - Save `$DATA_DIR/results/phase3/probe_aurocs.json`:
     ```json
     {
       "per_dataset": {
         "gsm_symbolic": {
           "20": {"real_auroc_mean": 0.91, "real_auroc_folds": [0.89, 0.92, ...], "random_auroc_mean": 0.52, "random_auroc_std": 0.03},
           ...
         },
         "folio": {...},
         "strategyqa": {...}
       },
       "pooled": {
         "20": {...}, ...
       },
       "top_layers": [20, 18, 22, 16, 24, 4],
       "best_layer": 20,
       "n_traces": {"gsm_symbolic": N, "folio": N, "strategyqa": N},
       "n_training_samples": {"gsm_symbolic": N*3, ...},
       "timestamp": "..."
     }
     ```
   - Generate comparison plot: `$DATA_DIR/results/phase3/probe_auroc_comparison.png`
     - X-axis: layer index (top-N layers only)
     - Y-axis: AUROC
     - One line per dataset + one for pooled (4 lines total)
     - Grey band: random-label mean +/- 2*std (from pooled)
     - Title: "Probe AUROC: Per-Dataset vs Pooled (top-N layers)"
   - Print summary: best layer per dataset, pooled vs per-dataset comparison, any selectivity warnings.

**Key constraints:**
- Fresh nnsight forward passes (locked decision).
- Label is ground_truth (Yes/No), NOT output token (Rho/Tau).
- Cast BF16 activations to float32 before training.
- All 36 layers saved as safetensors (trivial disk cost, needed for Phase 5).
- Training uses correct traces only for Pre-Handoff Window.
- No seed 42.
- No emoji.

**Usage:**
