  <action>
Create `scripts/layer_selection_pilot.py` that performs the two-stage layer selection pilot.

**Script structure:**

1. **Config and setup:**
   - `load_config("configs/phase3.yaml")` for configuration.
   - `setup_logging()`, `set_seed(cfg.seed)`.
   - Load dotenv for DATA_DIR.
   - Parse `--config` argument.

2. **Trace selection (`select_pilot_traces`):**
   - Walk `$DATA_DIR/traces/valid/{dataset}/{problem_id}/` directories.
   - Load trace JSON files (trace_00.json first).
   - Filter to single-think-block traces only (`count_think_blocks(token_ids) == 1`).
   - Separate into correct/incorrect per dataset.
   - Stratify: take roughly equal numbers per dataset, balanced by correctness where possible.
   - Target ~100 traces total (configurable via `cfg.phase3.pilot.n_traces`).
   - Return list of dicts: `{trace_path, token_ids, metadata, ground_truth, dataset}`.

3. **Activation extraction (`extract_pilot_activations`):**
   - Load model once on specified GPU via `load_model(gpu_id)`.
   - For each selected trace, run nnsight forward pass to extract residual stream at ALL 36 layers.
   - **CRITICAL: Use chunked capture** (12 layers per pass, 3 passes) to avoid OOM on long traces. Pattern from Phase 2:
     ```python
     chunk_size = 12
     for chunk_start in range(0, 36, chunk_size):
         chunk_layers = list(range(chunk_start, min(chunk_start + chunk_size, 36)))
         # Run nnsight trace with only these layers
         with model.trace(input_ids) as tracer:
             saved = {}
             for idx in range(36):  # MUST iterate all layers sequentially
                 if idx in set(chunk_layers):
                     saved[idx] = model.model.layers[idx].output.save()
         # Extract and store on CPU
         for idx in chunk_layers:
             tensor = saved[idx].detach().cpu().squeeze(0).float()  # [seq, 4096]
             # Extract Pre-Handoff Window positions only (not full sequence)
             window = get_pre_handoff_window(token_ids_list, window_size=3)
             if window:
                 start, end = window
                 training_vectors[idx].append(tensor[start:end])  # [3, 4096]
     ```
   - **Memory optimization**: Only keep Pre-Handoff Window vectors (3 positions per trace), not full sequences. This is ~100 traces x 3 positions x 4096 dims = ~1.2M floats per layer -- easily fits in RAM.
   - Accumulate training data: `X_per_layer[layer_idx]` = list of [3, 4096] tensors, `y_per_layer` = list of labels (0 or 1 from ground_truth).
   - Label encoding: `ground_truth == "Yes"` -> 1, `ground_truth == "No"` -> 0. Per locked decision, label is abstract validity, NOT output token.

4. **Probe training per layer (`train_layer_probes`):**
   - For each of 36 layers:
     - Concatenate all Pre-Handoff Window vectors: X = [n_traces * 3, 4096], y = [n_traces * 3].
     - Cast to float32 on GPU.
     - Run 5-fold stratified CV using `sklearn.model_selection.StratifiedKFold(n_splits=5, shuffle=True, random_state=137)`.
     - Per fold: train `nn.Linear(4096, 2)` with Adam (lr=1e-3, weight_decay=1e-4), CrossEntropyLoss, early stopping (patience=10, max 100 epochs). Record best validation AUROC.
     - Mean AUROC across 5 folds = layer AUROC.
   - Use the `train_probe` pattern from 03-RESEARCH.md code examples.
   - **Selectivity controls**: For each of 36 layers, also run 10 random-label permutations. Each permutation shuffles y, trains with same procedure, records mean CV AUROC. Report mean and std of random AUROCs per layer. Warn if any layer's random AUROC mean > 0.60.

5. **Layer selection (`select_top_layers`):**
   - Sort layers by real AUROC descending.
   - Select top-N layers (default 6 from config).
   - Strategy: best layer + 2 above + 2 below + 1 early layer (layer < 8 with best AUROC among early layers). If best layer is near the edges, adjust to fill N slots.
   - Also include the actual best layer for cosine similarity.

6. **Output:**
   - Save results to `$DATA_DIR/results/phase3/pilot_layer_aurocs.json`:
     ```json
     {
       "per_layer": {
         "0": {"real_auroc": 0.82, "random_auroc_mean": 0.51, "random_auroc_std": 0.03},
         "1": {...}, ...
       },
       "top_layers": [20, 18, 22, 16, 24, 4],
       "best_layer": 20,
       "n_traces_used": 100,
       "n_training_samples": 300,
       "datasets_represented": {"gsm_symbolic": 34, "folio": 33, "strategyqa": 33},
       "timestamp": "2026-02-26T..."
     }
     ```
   - Generate AUROC curve plot: `$DATA_DIR/results/phase3/pilot_auroc_curve.png`
     - X-axis: layer index (0-35)
     - Y-axis: AUROC
     - Blue line: real AUROC
     - Grey band: random-label mean +/- 2*std
     - Red dashed line at 0.60 (warning threshold)
     - Vertical green dashed lines at selected top-N layers
     - Title: "Layer Selection Pilot: AUROC per Layer (N=100 traces)"
     - No emoji in labels.
   - Print summary to stdout: best layer, top-N layers, AUROC at best layer, random AUROC at best layer.

**Key constraints:**
- Use fresh nnsight forward passes, NOT stored Phase 2 activations (locked decision).
- Chunked capture: 12 layers per pass to avoid OOM.
- Probes train on correct traces ONLY for the Pre-Handoff Window. But AUROC is computed on all traces (correct + incorrect) in each CV fold.
  - Wait -- actually, the training data is the Pre-Handoff Window of ALL correct traces. The CV split is within this training set. AUROC measures how well the probe discriminates Yes vs No labels within correct traces. But we need both Yes and No labels in the data (they come from ground_truth: some problems have ground_truth=Yes, others ground_truth=No, and we keep traces that answered CORRECTLY for those).
- Skip traces with no Pre-Handoff Window (no `</think>` token).
- Skip multi-think-block traces.
- No seed 42 anywhere.
