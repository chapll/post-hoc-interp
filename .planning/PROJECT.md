# Post-Hoc Interp: Mechanistic Detection of Performative Reasoning in Qwen 3.0

## What This Is

A mechanistic interpretability research project for Stanford CS224N that investigates whether reasoning tokens generated by Qwen 3.0 (8B) after the model has internally "decided" the correct answer are causally necessary or performative post-hoc rationalization. The project builds a pipeline to detect transition points in reasoning traces, validate them with causal interventions (activation patching and steering), and produce paper-ready quantitative and qualitative results across three datasets.

## Core Value

Identify the exact internal transition point where a model shifts from "searching" to "knowing" the answer, and provide mechanistic causal evidence (not just correlational probes) that post-transition tokens are performative.

## Requirements

### Validated

- Distributed training infrastructure (FSDP, tensor parallelism, checkpointing, Hydra config) -- existing
- Experiment logging with WandB -- existing
- Per-researcher isolated workspace (`src/experimental/{name}/`) -- existing

### Active

- [ ] Multi-GPU trace generation pipeline: run Qwen 3.0 8B with thinking mode, collect reasoning traces with residual stream activations, configurable GPU selection (specific IDs) and DDP across selected GPUs
- [ ] Dataset loading for GSM-Symbolic (verification subset), FOLIO (binary subset), StrategyQA -- 300 problems per dataset, configurable N traces per problem (5 for probing, 20 for differential analysis)
- [ ] Trace-specific transition detection: logistic regression probe on residual stream activations at each token position, identify transition point T_i where probe confidence consistently exceeds 95%
- [ ] Intrinsic phase analysis: cosine similarity dynamics of residual stream (step-wise similarity S_t), test hypothesis that pre-transition states show high drift and post-transition states show high stability
- [ ] Differential state analysis: cluster traces into "Concise" vs "Performative" groups, isolate performativity vector by subtracting mean residual stream states aligned at T_i
- [ ] Causal steering validation: inject performativity vector into concise traces to induce unnecessary generation, inject inverse into verbose traces to induce early termination
- [ ] Attention pattern classification: classify attention heads as "Reasoning" vs "Consistency" heads, analyze whether post-transition tokens are dominated by consistency heads
- [ ] Baseline comparisons: greedy pruning, PNS-based optimization, P-ALIGN binary search
- [ ] Quantitative evaluation: probe AUROC at intermediate steps, token reduction ratio (1 - T/n), steering success rate
- [ ] Qualitative evaluation: attention pattern visualizations for pre/post transition regions
- [ ] Saved annotated traces: each trace stored with per-token probe confidence, transition point, token classification (necessary vs performative)
- [ ] Paper-ready figures: transition point distributions, cosine similarity phase plots, steering success rates, attention pattern heatmaps, ablation results

### Out of Scope

- TAPO (Transition-Aware Policy Optimization) -- stretch goal, defer unless core pipeline is complete early
- Models other than Qwen 3.0 8B -- scope limited to one model for depth over breadth
- Training or fine-tuning Qwen -- this is an analysis project, model is used inference-only
- Real-time or interactive demo -- research code, not a product

## Context

- This is a CS224N final project (Ali Ahmad, Gorn Namchittai, Eric Cui)
- Based on the DeepSeek-R1 paper which showed reasoning emerges from pure RL but left open whether all reasoning tokens are necessary
- Prior work (Cox 2025, Zhang et al. 2025) used linear probes to show models encode correct answers early, but stopped at correlation -- this project aims for causal mechanistic evidence
- Qwen 3.0 has an explicit "Unified Thinking Mode" with `enable_thinking=True`, making it ideal for studying allocated reasoning budget
- All code lives in `src/experimental/gorn/` but may use any infrastructure from the repo
- Hardware: A100 80GB GPUs, 4+ available
- Interpretability library: nnsight (hooks-based, works with any HF model)
- Sampling parameters per Qwen 3.0 thinking mode docs: Temperature=0.6, TopP=0.95, TopK=20, MinP=0

## Constraints

- **Workspace**: All new code in `src/experimental/gorn/` -- shared repo with other researchers
- **GPU selection**: Must support specifying exact GPU IDs (e.g., GPUs 1 and 7) AND distributed data parallel across selected GPUs for throughput
- **No mocks/fallbacks**: Every component must be real. Failures must propagate loudly with clear tracebacks
- **No emoji**: Not in code, comments, print statements, or logs
- **Plain text output**: Simple print statements, no decorative formatting
- **No seed 42**: Use any other seed value
- **Model**: Qwen 3.0 8B only (Qwen/Qwen3-8B from HuggingFace)
- **Interpretability**: nnsight library for activation access and causal interventions
- **Inference only**: No training or fine-tuning of the base model
