**Function: `plot_transition_curves(df, output_dir)`**
Generate the primary side-by-side figure: accuracy (left) and probability (right).
NOTE: This function is the one that satisfies the locked decision "all 3 datasets on one plot, color-coded" -- both panels show all datasets overlaid with distinct colors.

Left panel (Accuracy vs Position):
- For each dataset: group by normalized_position, compute mean accuracy
- 95% CI for proportions: `1.96 * sqrt(p*(1-p)/n)` (binomial CI)
- Plot line + shaded CI band per dataset
- Also plot aggregate (all datasets combined) as a dashed black line
- X-axis: "Normalized Position in Thinking Block" (0 to 1)
- Y-axis: "Accuracy" (0 to 1)
- Add horizontal line at 0.5 (chance level) as light gray dashed
- Grid, legend

Right panel (Probability vs Position):
- For each dataset: group by normalized_position, compute mean correct_token_prob
- 95% CI: `1.96 * sem`
- Plot line + shaded CI band per dataset
- Same x-axis as left
- Y-axis: "P(correct answer token)"
- Add horizontal line at 0.5 as light gray dashed
- Grid, legend

Save as `transition_curves.png`
