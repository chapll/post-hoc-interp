Create `scripts/force_answer_experiment.py` -- the core experiment script. Structure:

**Imports and constants:**
- `from src.model import load_model`
- `from src.config import load_config`
- `from src.utils import setup_logging, set_seed`
- Standard: `json, os, copy, random, time`
- `import torch`, `import numpy as np`, `import pandas as pd`
- `from transformers import DynamicCache`
- `from tqdm import tqdm`

**Constants (at module level):**
```python
RHO_TOKEN_IDS = [49, 6161]       # "R" + "ho" (two tokens)
RHO_FIRST_TOKEN_ID = 49          # first token of Rho
TAU_TOKEN_ID = 92713             # single token
CLOSE_TOKEN_IDS = [151668, 198]  # </think> + \n
```

**Function: `load_traces_for_experiment(traces_dir, cfg)`**
- Walk `traces_dir/valid/{dataset}/` for gsm_symbolic, folio, strategyqa
- Load trace_00.json from each problem directory
- Filter: must have `has_think=true` and `num_think_blocks=1`
- Determine correctness: read `valid_token` and `ground_truth` from metadata. If `ground_truth == "Yes"`, expected token is `valid_token`; if "No", expected token is `invalid_token`. Check if expected token (case-insensitive) appears in the generated text after the last `</think>`.
- Separate into correct and incorrect lists per dataset
- Use `random.Random(cfg.force_answer.selection_seed)` for reproducible selection
- Allocate ~proportionally: for each dataset, take `round(n_correct * n_per_dataset / total)` correct and fill remainder with incorrect
- For GSM-Symbolic: include both fresh and original instances (do not filter by is_fresh)
- Return list of dicts: `{trace_path, token_ids, metadata, is_correct, dataset}`
- Log: how many traces per dataset, how many correct/incorrect

**Function: `compute_probe_positions(think_length, num_probes=20, min_spacing=5)`**
- Adjust num_probes: `max_probes = max(1, think_length // min_spacing)`, then `actual = min(num_probes, max_probes)`
- If actual <= 1, return `[think_length // 2]`
- Use `np.linspace(0, think_length - 1, actual, dtype=int)`
- Remove duplicates, return sorted list
- Positions are 0-indexed relative to thinking content start (token after `<think>`)

**Function: `extract_answer(generated_ids, generated_text, valid_token, invalid_token)`**
- Token-level: scan generated_ids for first occurrence of TAU_TOKEN_ID or RHO_FIRST_TOKEN_ID (check next token is RHO_TOKEN_IDS[1] for Rho)
- String-level: check if "rho" or "tau" (case-insensitive) in generated_text. If both, take whichever appears first.
- If neither found: return `{answer: None, correct: False, no_answer: True, token_answer: None, string_answer: None, agreement: True}`
- Otherwise: determine correctness by comparing answer to valid_token (if correct answer expected) or invalid_token. Specifically: the expected answer token is `valid_token` if `ground_truth == "Yes"` else `invalid_token`. The answer is correct if `answer == expected_token`.
- NOTE: The `expected_token` must be passed in or derived. Better: pass `expected_token` directly to this function.
- Return dict: `{answer, correct, no_answer, token_answer, string_answer, agreement}`

**Function: `extract_rho_tau_probs(first_logits)`**
- Apply float32 softmax to first_logits
- Extract `probs[RHO_FIRST_TOKEN_ID]` as rho_prob and `probs[TAU_TOKEN_ID]` as tau_prob
- **Compute correct_token_rank**: Use `torch.argsort(probs, descending=True)` to get token indices sorted by probability. Find the rank (0-indexed position in the sorted order) of the correct answer's first token ID. The caller will pass in the correct token ID (RHO_FIRST_TOKEN_ID or TAU_TOKEN_ID depending on which is the expected answer). Return rank as an int.
- Updated signature: `extract_rho_tau_probs(first_logits, correct_first_token_id)`
- Return `{rho_prob: float, tau_prob: float, correct_token_rank: int}`

**Function: `probe_trace(raw_model, tokenizer, trace_data, cfg, device)`**
- Extract think_start, think_end from `metadata.think_boundaries[0]`
- Compute think_length = think_end - think_start - 1 (content tokens between boundaries)
- Compute probe_positions using compute_probe_positions()
- Determine expected_token: `valid_token if ground_truth == "Yes" else invalid_token`
- Determine correct_first_token_id: `RHO_FIRST_TOKEN_ID if expected_token == "Rho" else TAU_TOKEN_ID`

- **KV cache approach (primary):**
  - Build full_input_ids = token_ids[:think_start + 1] + token_ids[think_start+1 : think_start+1+think_length]
    (i.e., everything from prompt through thinking content, stopping before `</think>`)
  - Forward pass to prefill the cache:
    ```python
    full_tensor = torch.tensor([full_input_ids], dtype=torch.long, device=device)
    cache = DynamicCache()
    with torch.no_grad():
        raw_model(input_ids=full_tensor, past_key_values=cache, use_cache=True)
    ```
    NOTE: Use `DynamicCache()` with no arguments. The config= kwarg is optional and unnecessary here.
  - Process probes in DESCENDING order (rightmost first, so crop only removes from end):
    - For each probe position pos (relative to think content start):
      - cache_len = len(prefix_ids) + pos  where prefix_ids = token_ids[:think_start+1]
      - cache.crop(cache_len)
      - Build input_for_generate = full_input_ids[:cache_len] + CLOSE_TOKEN_IDS
      - input_tensor = torch.tensor([input_for_generate], device=device)
      - attention_mask = torch.ones_like(input_tensor)
      - IMPORTANT: deepcopy the cache before passing to generate (generate mutates it)
      - gen_output = raw_model.generate(input_ids=input_tensor, attention_mask=attention_mask, past_key_values=copy.deepcopy(cache), max_new_tokens=cfg.force_answer.max_new_tokens, do_sample=False, return_dict_in_generate=True, output_logits=True)
      - Extract generated_ids = gen_output.sequences[0, len(input_for_generate):].tolist()
      - Decode generated_text = tokenizer.decode(generated_ids, skip_special_tokens=False)
      - Extract first_logits = gen_output.logits[0][0] (shape [vocab_size])
      - Call extract_answer() and extract_rho_tau_probs(first_logits, correct_first_token_id)
      - Compute normalized_position = pos / (think_length - 1) if think_length > 1 else 0.5
      - Build result row dict (include correct_token_rank from extract_rho_tau_probs return)

  - **Fallback**: If DynamicCache raises any error during prefill or crop, fall back to the simple approach (Pattern 2 from research): for each probe position, construct input from scratch and call generate() without cache reuse. Log a warning when falling back.

- Return list of result row dicts, one per probe position

- Build DataFrame from all_results with columns:
  - trace_id (str: problem_id from metadata)

  - ground_truth (str: "Yes" or "No")
  - is_correct_trace (bool: whether the original trace was correct)
