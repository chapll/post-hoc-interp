  <action>
Create `src/experimental/gorn/scripts/check_traces.py` with:

**Main function (`main()`):**
1. Load config via `load_config()` (to get paths.traces_dir)
2. Scan `{traces_dir}/valid/` recursively for all `trace_*.json` files using `glob.glob` or `pathlib.Path.rglob`
3. Parse each JSON file and run quality checks
4. Compute length statistics (mean, std, p5, p95) across all traces for outlier detection
5. Write CSV report to `{traces_dir}/quality_report.csv`
6. Print summary to stdout

**Quality checks per trace (objective -- hard pass/fail):**
- `has_think_block`: Parse `token_ids` via `parse_think_boundaries()`, check `len(blocks) > 0`. FAIL if no think block.
- `hit_max_tokens`: Check `metadata.hit_max_tokens` field. FAIL if True (means generation was truncated).
- `degenerate_repetition`: Check if any single token repeats more than 50 consecutive times in `token_ids`. FAIL if True. Implement this check inline (simple consecutive count loop -- see research doc for pattern).

**Warning flags per trace (subjective -- flag only, do not auto-reject):**
- `length_outlier`: After computing p5 and p95 of all token counts, flag any trace outside [p5, p95]. This is a WARNING, not a FAIL.
- `multi_block`: Check `num_think_blocks > 1` from metadata or recompute from token_ids. This is a WARNING.

**CSV columns:**
`dataset,problem_id,trace_index,num_tokens,num_think_blocks,has_think_block,hit_max_tokens,degenerate_repetition,length_outlier,pass_all,file_path`

Where `pass_all` = True only if all three objective checks pass (has_think_block=True, hit_max_tokens=False, degenerate_repetition=False). Warning flags do NOT affect pass_all.

**Summary output (print to stdout):**
```
Quality Report: {traces_dir}/quality_report.csv
Total traces scanned: {N}
  PASS: {n_pass}
  FAIL: {n_fail}
    no_think_block: {count}
    hit_max_tokens: {count}
    degenerate_repetition: {count}
  WARNINGS:
    length_outlier: {count}
    multi_block: {count}

Per-dataset breakdown:
  gsm_symbolic: {pass}/{total} pass
  folio: {pass}/{total} pass
  strategyqa: {pass}/{total} pass
```

**Quarantine helper:** After the summary, if any traces failed, print a suggestion:
```
To quarantine failed traces, review the report and run:
  python src/experimental/gorn/scripts/check_traces.py --quarantine
```

Also implement a `--quarantine` flag that:
1. Reads the CSV report
2. For each trace where `pass_all=False`, moves the JSON file from `valid/` to `failed/` (using os.rename, creating failed/ subdirs as needed)
3. Logs each move
4. This is a separate mode, not auto-triggered

**Important:** Use argparse for --quarantine flag, integrated with load_config() for other args.

Do NOT auto-reject or auto-move any traces during the default scan mode. The default mode is purely diagnostic.
