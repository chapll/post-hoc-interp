  <name>Task 1: Create verify_phase2.py verification script</name>
  <files>src/experimental/gorn/scripts/verify_phase2.py</files>
  <action>
Create `src/experimental/gorn/scripts/verify_phase2.py` that verifies all Phase 2 outputs:

**Verification checks (using same record() pattern from Phase 1 validate.py):**

1. **Trace completeness:**
   - Count all JSON files in `data/traces/valid/` per dataset
   - Expected: ~200 GSM-Symbolic (100 fresh + 100 original, each with Yes/No = 200 problems, but each problem has 5 traces = 1000 trace files), ~100 FOLIO problems x 5 = 500 traces, ~100 StrategyQA x 5 = 500 traces
   - NOTE: Exact counts may vary due to balancing. Check that per-dataset counts are within 80% of expected (not exact match since minority class capping may reduce counts).
   - Record per-dataset: total, valid, failed

2. **Trace metadata integrity (sample 10 traces per dataset):**
   - Load JSON, verify required fields exist: token_ids, generated_text, metadata
   - Verify metadata has: problem_id, dataset_name, ground_truth, trace_index, seed, num_tokens, num_think_blocks, model_name, temperature, top_p, top_k, timestamp
   - Verify token_ids is a non-empty list of ints
   - Verify generated_text is a non-empty string
   - Verify seed != 42

3. **Think block integrity (sample 10 traces per dataset):**
   - Parse token_ids via parse_think_boundaries()
   - Verify at least 1 block exists (since these are in valid/)
   - Verify num_think_blocks in metadata matches actual parse result

4. **GSM-Symbolic contamination coverage:**
   - Count traces with is_fresh=True vs is_fresh=False
   - Both should be non-zero
   - Log the ratio

5. **Seed reproducibility (sample 3 traces):**
   - For 3 randomly selected traces, recompute derive_trace_seed(problem_id, trace_index) and verify it matches the seed in metadata

6. **Quality report existence:**
   - Check that quality_report.csv exists in traces_dir
   - Load it, verify it has expected columns
   - Report pass/fail counts

7. **Activation completeness (if activations exist):**
   - For each trace in valid/, check if corresponding safetensors exists in activations/
   - Count: captured, missing, percentage
   - This check is informational -- activations may not exist yet if capture hasn't run

8. **Activation shape verification (sample 5 traces with activations):**
   - Load safetensors via load_file()
   - Verify 36 residual_layer_* keys exist (layer 0 through 35)
   - Verify each has shape [seq_len, 4096] (batch dim squeezed)
   - Verify topk_values shape [seq_len, 50]
   - Verify topk_indices shape [seq_len, 50]
   - Verify entropy shape [seq_len]
   - Verify token_ids shape [seq_len] (int32)
   - Verify seq_len matches the trace JSON's num_tokens

9. **Disk usage summary:**
   - Total size of data/traces/ directory
   - Total size of data/activations/ directory (if exists)
   - Print human-readable sizes

**Output format:** Same as Phase 1 validate.py -- a summary table with PASS/FAIL per check, total counts.

**Run command:** `uv run python src/experimental/gorn/scripts/verify_phase2.py --config src/experimental/gorn/configs/capture.yaml`
