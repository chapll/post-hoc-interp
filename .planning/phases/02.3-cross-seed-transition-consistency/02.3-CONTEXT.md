# Phase 2.3: Cross-Seed Transition Consistency - Context

**Gathered:** 2026-02-23
**Status:** Ready for planning

<domain>
## Phase Boundary

For each problem, generate 20 traces (different seeds) and probe all of them at ~20 positions to determine whether the model's transition from "not knowing" to "knowing" the correct answer occurs at a consistent normalized position across seeds. Per-problem visualization (mean + individual seed curves) and cross-seed agreement quantification (sharpness, variance, correlation). Small pilot: same ~51 problems from Phase 2.2, only originally correct ones (~40 problems).

</domain>

<decisions>
## Implementation Decisions

### Transition definition
- Track both binary correctness AND P(correct token) at each probe position (same metrics as Phase 2.2 plus rank)
- No formal transition point detection -- just plot the raw data per trace and visually inspect
- No-answer cases kept as a separate category (distinct from incorrect), same as Phase 2.2
- Record P(correct token), logit rank, and binary correctness -- full metric set from 2.2

### Problem selection & trace generation
- Same ~51 problems from Phase 2.2 selection, filtered to only originally correct ones (~40 problems)
- Generate 20 traces per problem (17 new + 3 existing = 20 total)
- Same generation parameters as Phase 2: temperature=0.6, top_p=0.95, top_k=20
- New traces use the existing `generate_traces.py` infrastructure with different seed offsets
- Only single-think-block traces are eligible (same filter as 2.2)

### Per-problem visualization
- One PNG per problem, stored in a subfolder within the output dir (e.g., `$EXP_DIR/force_answer_seeds/per_problem/`)
- Each plot has two side-by-side panels:
  - Left: binary accuracy (bold mean across 20 seeds + faint individual seed curves)
  - Right: P(correct token) (bold mean + faint individual seed curves)
- X-axis: normalized position (0-1) in both panels
- A summary overview plot: histogram of transition dynamics across all problems (goes in the main output dir)

### Cross-seed agreement quantification
- Mean accuracy curve sharpness: measure the max slope of the mean accuracy curve per problem
- Position-wise variance: at each normalized position, compute variance of correctness across 20 seeds. Low variance = seeds agree.
- Pairwise Spearman correlation: correlate seed pairs' accuracy curves. High correlation = consistent transition dynamics.
- Report metrics per problem, no categorical grouping (let data speak)
- Aggregate metrics only (no per-dataset breakdown)
- Defer fresh vs original GSM-Symbolic contamination comparison

### Claude's Discretion
- Exact generation approach for 17 new traces (reuse generate_traces.py or minimal standalone script)
- How to handle problems where some of the 20 seeds produce multi-think-block or no-think traces (skip those seeds)
- Exact colors/styling for per-problem plots
- Summary plot design (histogram bins, what metric to show)
- Whether to reuse Phase 2.2's force_answer_experiment.py directly or create a new script

</decisions>

<specifics>
## Specific Ideas

- The core question: "Is there a consistent point at which the model knows the answer, regardless of the random path it took to get there?" If yes, this is strong evidence for an internal phase transition independent of the reasoning path.
- With 20 seeds, we can distinguish genuine transitions from lucky guesses -- if 18/20 seeds flip to correct at the same normalized position, that's compelling.
- Problems where the model NEVER knows (flat at 0% across all positions and seeds) or ALWAYS knows (flat at 100%) are uninteresting for transition analysis but should be reported in summary statistics.

</specifics>

- Denser probe spacing near detected transition regions
