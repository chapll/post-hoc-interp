Create `src/transition.py` as a standalone library module. It accepts arrays of (position, value) and returns segmentation results. Per CONTEXT.md Decision 4, this is the single source of truth for transition detection.

**Public API:**
```python
def detect_transitions(
    positions: np.ndarray,
    values: np.ndarray,
    methods: list[str] = ["derivative", "pelt", "binseg", "sigmoid"],
    config: dict | None = None,
) -> dict:
    """Run all specified detection methods on a (positions, values) curve.

    Args:
        positions: Array of token positions (integers or floats).
        values: Array of signal values (e.g., probe confidence in [0, 1]).
        methods: List of method names to run.
        config: Optional dict of method-specific parameters. If None, uses defaults.

    Returns:
        Dict keyed by method name, each containing:
        - transition_point: int or None (position value, not index)
        - plateau_onset: int or None (position value)
        - segments: list of (start, end, label) tuples
        - classification: "clear" | "no-signal" | "noisy-signal"
        - method_specific: dict of method-specific metadata
    """
```

**Internal methods (all private with underscore prefix):**

1. `_derivative_method(positions, values, config)`:
   - Use `scipy.signal.savgol_filter` with `deriv=1` for smoothed first derivative. Smoothing is ONLY for derivative computation (per locked decision).
   - Find first point where slope exceeds `slope_threshold` (default 0.01).
   - Plateau detection on RAW values: check if mean of last 10 raw values > 0.90.
   - Classification: "no-signal" if max(values) < 0.70, "clear" if slope onset found AND plateau detected, "noisy-signal" otherwise.
   - Handle short signals: adjust window_length to be odd and <= len(values), minimum 5.
   - Return transition_point (position value at onset), derivative array, classification.

2. `_pelt_method(positions, values, config)`:
   - Use `ruptures.Pelt(model="l2", min_size=5)` on RAW values (no smoothing).
   - Run with a single penalty value from config (caller sweeps externally).
   - `signal = values.reshape(-1, 1)` -- ruptures expects 2D.
   - `change_points = algo.predict(pen=pen)` -- last element is always len(signal), filter it out.
   - First change point is candidate transition.
   - Classification: "no-signal" if max(values) < 0.70 and no change points, "clear" if change points found, "noisy-signal" if max > 0.70 but no change points.
   - Return change_points list, transition_point (position value), classification.

3. `_binseg_method(positions, values, config)`:
   - Use `ruptures.Binseg(model="l2", min_size=5)`.
   - `predict(n_bkps=n_bkps)` with n_bkps from config (default 2).
   - Same classification logic as PELT.
   - Return change_points, transition_point, classification.

4. `_sigmoid_method(positions, values, config)`:
   - Define logistic sigmoid: `L / (1 + exp(-k * (x - x0))) + b`
   - Use `scipy.optimize.curve_fit` with initial guesses:
     - L = max(y) - min(y), k = 1/(std(x) + 1e-8), x0 = median(x), b = min(y)
   - Bounds: L in [0, 1.5], k in [0, inf], x0 in [x.min(), x.max()], b in [-0.1, 0.5].
   - `maxfev=5000` for convergence.
   - Compute R-squared from residuals.
   - Report results for all r2_thresholds from config (default [0.75, 0.80, 0.85, 0.90, 0.95]). Classification uses the primary threshold (0.85 by default) but all thresholds reported in method_specific.
   - transition_point = x0 (midpoint of sigmoid), sharpness = k.
   - Wrap in try/except for RuntimeError/ValueError -- return "noisy-signal" classification with error message if fit fails.

5. `_build_segments(positions, transition_idx, plateau_idx)`:
   - Helper to build three-phase segments: (start, transition, "reasoning"), (transition, plateau, "transition"), (plateau, end, "post-hoc").
   - If no transition: single segment (start, end, "reasoning").
   - If transition but no plateau: (start, transition, "reasoning"), (transition, end, "transition").

**Classification logic (shared helper `_classify_trace`):**
- "no-signal": max(values) < 0.70 (probe never gets confident)
- "clear": transition detected AND plateau detected (last N values above threshold)
- "noisy-signal": everything else (has some signal but no clean segmentation)

**IMPORTANT constraints:**
- All detection methods operate on RAW values. Smoothing only for derivative computation.
- No emoji, no seed 42.
- Module has no dependencies on project-specific code (no imports from src.*). It only uses numpy, scipy, and ruptures. This makes it reusable for any (position, value) curve.
- Include comprehensive docstrings.
- Use logging (not print) for warnings.
