  <name>Task 1: Create validation config and end-to-end validation script</name>
  <files>
    src/experimental/gorn/configs/validate.yaml

  </files>
  <action>
    **validate.yaml** -- Config for validation run (small scale):
    ```yaml
    data:
      datasets:
        - gsm_symbolic
        - folio
        - strategyqa
      problems_per_dataset: 6

    model:
      max_new_tokens: 4096

    storage:
      layer_subset: [0, 4, 8, 12, 16, 20, 24, 28, 32, 35]
      top_k_logits: 50
      save_attention: false

    validation:
      verify_round_trip: true
      verify_shapes: true
      verify_think_tokens: true
    ```

    **validate.py** -- End-to-end validation script. Structure:

    1. **Parse args and load config:**
       - Use load_config() from lib/config.py
       - Accept --config flag pointing to validate.yaml
       - Accept --gpus flag for GPU selection

    2. **Dataset validation:**
       - Load 6 problems from each dataset using load_dataset_by_name
       - Print counts: total, true, false per dataset
       - Verify balance (equal true/false)
       - Verify schema (all required fields present)
       - Verify GSM-Symbolic distractors differ from correct answers
       - Verify all prompts contain "Please think step-by-step"

    3. **Model + trace generation validation (single GPU):**
       - Load model on first GPU from config
       - For first 2 problems from each dataset (6 total):
         a. Generate trace using generate_trace
         b. Parse think boundaries from output token IDs
         c. Log: prompt length, output length, num think blocks, think content length
         d. Capture activations using capture_activations
         e. Prepare trace tensors using prepare_trace_tensors
         f. Save trace to temp directory using save_trace
         g. Save metadata using save_metadata
         h. Load trace back using load_trace
         i. Verify round-trip: compare every tensor key, shape, dtype, and values (torch.equal)
         j. Print PASS/FAIL for each check

    4. **Shape verification:**
       - For each captured trace, verify:
         - residual_layer_{i} shape is [1, seq_len, 4096] for each layer in subset
         - last_token_layer_{i} shape is [1, 4096] for all 36 layers
         - logits shape is [1, seq_len, vocab_size]
         - topk_values shape is [seq_len, 50]
         - topk_indices shape is [seq_len, 50]
         - entropy shape is [seq_len]
         - token_ids shape is [seq_len]

    5. **Think token validation:**
       - Verify at least one think block found in each trace
       - Verify pre-handoff window can be extracted
       - Log think block positions and lengths

    6. **Multi-GPU validation (MANDATORY):**
       - Define a simple worker function that loads model, generates one trace, and saves it
       - Detect available GPUs: if >= 2, run with run_parallel on 2 GPUs
       - Verify all workers completed (check output files exist)
       - If only 1 GPU available, print error and exit with code 1: "Multi-GPU validation required per CONTEXT.md. Run on a machine with 2+ GPUs."
       - This is a hard requirement from the locked decisions: "Validate both single-GPU and multi-GPU (2+ GPUs) spawning in Phase 1"

    7. **Summary:**
       - Print final summary table: dataset, num_problems, traces_generated, round_trip_passed, shapes_correct, think_blocks_found
       - Print overall PASS/FAIL

    **Output structure in temp dir:**
    ```
    {temp_dir}/traces/{dataset}/{problem_id}/trace_00.safetensors
    {temp_dir}/traces/{dataset}/{problem_id}/trace_00.json
    ```

    **Important:**
    - No emoji anywhere
    - No mock data -- real model, real datasets, real generation
    - Any failure should print clear error with context and continue to next check (do not abort on first failure)
    - Use plain text print statements for all output
    - At the end, if any check failed, exit with code 1
    - This script REQUIRES GPU access. If no GPU, it should fail immediately with clear error.
