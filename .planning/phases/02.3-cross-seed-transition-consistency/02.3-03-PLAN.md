**Function: `interpolate_seed_curves(df_problem, grid, metric="correct")`**
Interpolate a metric across seeds to a common grid for a single problem.

- Args: df_problem (filtered to one problem_id), grid (np.array of normalized positions), metric (column name: "correct" or "correct_token_prob")
- For each seed_index in the dataframe:
  - Sort by normalized_position
  - Get x = normalized_position values, y = metric values (cast "correct" to float)
  - Interpolate: `np.interp(grid, x, y)`
  - Append to list
- Return: np.array of shape (n_seeds, len(grid)), plus the list of seed_indices

**Function: `compute_agreement_metrics(acc_matrix, grid)`**
Compute the three cross-seed agreement metrics from an accuracy matrix.

Implementation per CONTEXT.md locked decisions and RESEARCH.md Example 4:

1. **Sharpness (max slope of mean curve):**
   - `mean_acc = acc_matrix.mean(axis=0)`
   - `diffs = np.diff(mean_acc) / np.diff(grid)`
   - `sharpness = float(np.max(np.abs(diffs)))`

2. **Position-wise variance:**
   - `pos_variance = acc_matrix.var(axis=0)` (variance across seeds at each position)
   - `mean_pos_variance = float(pos_variance.mean())`
   - `max_pos_variance = float(pos_variance.max())`

3. **Pairwise Spearman correlation:**
   - For all pairs (i, j) where i < j:
     - `rho, _ = spearmanr(acc_matrix[i], acc_matrix[j])`
     - Append rho if not NaN
   - `mean_spearman = float(np.mean(correlations))` if any, else NaN

Return dict: `{"sharpness": ..., "mean_pos_variance": ..., "max_pos_variance": ..., "mean_pairwise_spearman": ..., "n_seeds": acc_matrix.shape[0]}`
